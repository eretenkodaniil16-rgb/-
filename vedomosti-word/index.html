Генератор ведомостей для Word

Ничего скачивать из браузера не нужно. Разметьте списки, подготовьте документ, скопируйте его в Word и сохраните средствами Word.

Выбрать исходный файл
DOC/DOCX/RTF/TXT, XLS/XLSX/XLSM, CSV и другие

Ручная разметка

Выберите строку с группой → «Взять группу». Затем выделите фамилии и нажмите А или Б. Shift + щелчок выделяет диапазон.

Готовый документ

Нажмите «Копировать в Word» → откройте Microsoft Word → Ctrl+V → Файл → Сохранить как. Если автоматическое копирование не сработает, нажмите «Выделить документ», затем Ctrl+C.

Конфиденциальность

Исходный файл читается только локально на рабочем ПК. Данные студентов не отправляются на GitHub, сервер или облако. Готовая таблица копируется напрямую из браузера в Word.
